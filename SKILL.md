# Creating Viral Short Dramas

## Core principle

Preserve the story promise first. Hooks earn attention only when the episode pays them off; internet-native wording may change expression, never facts, relationships, motives, or outcomes.

## Required upstream skills

Load only the skills needed for the selected route:

- **REQUIRED SUB-SKILL:** `short-drama-develop` for ideas, adaptations, story engines, episode maps, or series development.
- **REQUIRED SUB-SKILL:** `short-drama-write` for writing, continuing, or surgically revising a shootable episode.
- **REQUIRED SUB-SKILL:** `viral-hooks` for the first 1–3 seconds and its visual, spoken, and on-screen-text layers.
- **REQUIRED SUB-SKILL:** `viral-short-form` for retention, escalation, payoff, and ending structure.
- **REQUIRED SUB-SKILL:** `xiaohongshu-netfeel-guardian` for Chinese phrasing, translation-tone cleanup, and AI-like wording cleanup.
- **REQUIRED SUB-SKILL:** `short-drama-review` for a requested review or the final integrity check of a complete episode.

## Route by request

| Request | Route |
|---|---|
| Develop a series from an idea or source | develop → hooks/retention → write → netfeel → review |
| Write or continue one episode | write → hooks/retention → netfeel → review |
| Improve only the opening | viral-hooks → netfeel → payoff check |
| Revise an existing script | review → surgical write revision → hooks only where relevant → netfeel |
| Review or diagnose an existing episode | review → findings and prioritized revision advice; do not rewrite unless asked |
| Polish only dialogue | netfeel → character and plot integrity check |

Use the shortest matching route. A local edit remains local.

## Invariants

- Treat confirmed premise, character desire, causality, relationships, and outcomes as the story contract.
- Extract hooks from real stakes, choices, reversals, or information already paid off in the episode.
- If a proposed hook cannot be paid off, weaken or replace the hook. Do not rewrite unrelated plot to justify it.
- Every hook delivered to the user, including alternatives, must individually name a payoff that proves its exact promise; revise, downgrade, or discard any candidate that cannot.
- Without user-provided voice samples, label the voice as general Chinese internet-native wording; do not claim imitation of a specific creator.
- Do not impose one explosion count, timestamp formula, or template on every genre and duration.
- When editing dialogue, preserve speaker intent, power relationship, facts, and resulting action.

## Deliverable contract

For a complete creation, deliver in this order:

1. Story promise and audience emotion payoff.
2. Episode goal, conflict, turn, and cliffhanger.
3. Three hooks using different mechanisms; for each, name the exact promise and its payoff beat, then recommend one.
4. Shootable Chinese scene script.
5. Only material voice changes that affect character sound or comprehension.
6. Integrity check: hook paid off, character consistent, causality intact, no obvious translation tone.

For a partial request, return only the requested artifact plus the relevant integrity check. For a review-only diagnosis, return findings and prioritized revision advice without rewritten episode text unless the user asks for a rewrite.

## Quick reference

| Symptom | Correction |
|---|---|
| Hook is exciting but unrelated | Replace it with the strongest true stake or reversal |
| Dialogue sounds like translated copy | Keep intent and power, rewrite only spoken expression |
| Every scene has the same rhythm | Vary pressure, information, action, and exit point |
| Revision keeps expanding | Return to the named lines or scenes |
| “Platform voice” has no samples | Use general internet-native Chinese and disclose the limit |

## Example

If the user asks to polish two lines, load the netfeel skill, preserve both lines' intent and relationship, return the revised lines and a one-line integrity check. Do not create hooks, an episode outline, or a full script.

## Common mistakes

- Treating social-video formulas as story causality.
- Making every character speak in the same trendy voice.
- Hiding a weak payoff behind a louder hook.
- Claiming a specific creator voice without examples.
- Running the full pipeline for a local edit.
